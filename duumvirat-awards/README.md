# Duumvirat Awards 2026

Сайт голосования: без регистрации, один голос в каждой номинации с одного браузера.
Зависимостей нет, нужен только Node.js 20+.

```bash
npm start            # http://localhost:3000
```

- Номинации и кандидаты — в `categories.json` (после правки перезапустите сервер; `id` уже
  существующих кандидатов не меняйте, иначе их голоса потеряются).
- Голоса сохраняются в `storage/votes.json`.
- Итоги скрыты. Чтобы посмотреть их, запустите с `ADMIN_TOKEN=секрет` и выполните
  `curl -H "Authorization: Bearer секрет" http://localhost:3000/api/results`.

Переменные окружения: `PORT`, `STORAGE_DIR`, `ADMIN_TOKEN`, `RATE_LIMIT` (голосов с одного IP
за 10 минут, по умолчанию 60), `TRUST_PROXY=1` (если сайт стоит за обратным прокси).

Повторные голоса отсекаются по анонимной cookie и ограничению частоты с одного IP. Это защита
от случайных и ленивых накруток, а не гарантия «один человек — один голос».
