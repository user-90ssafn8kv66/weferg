# outfit-picker

Собирает образ из реальных объявлений Авито по пожеланиям и вещам, которые уже есть.

```bash
python -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/outfit "деловой мужской образ на осень до 20 тыс, размер 50. У меня есть чёрные туфли" --city moskva
.venv/bin/outfit --have "синие джинсы" --have "белые кеды" --style street --budget 8000 --json
```

Веб-интерфейс: `.venv/bin/outfit-web` (на Windows `.venv\Scripts\outfit-web`) — откроется страница
http://127.0.0.1:8000/.

Из текста извлекаются пол, стиль, сезон, цвета, бюджет, размеры, названные вещи («с красным платьем»)
и имеющиеся вещи (после «есть …» или через `--have`). Для недостающих частей образа делается по одному
поиску на Авито, затем выбирается комбинация, которая укладывается в бюджет и сочетается по цветам
между собой и с имеющимися вещами.

```python
from outfit_picker import make_client, parse_wishes, pick_outfit

outfit = pick_outfit(parse_wishes("летний образ до 7000", have=["белые кроссовки"]), make_client())
```

Обычные HTTP-клиенты Авито отклоняет (HTTP 429), поэтому поиск открывается в настоящем браузере через
Playwright: используется установленный Chrome или Edge, окно не показывается. Если Авито попросит пройти
проверку, запустите с `--show-browser` и пройдите её в открывшемся окне — профиль браузера сохраняется,
так что это нужно сделать один раз. Без Chrome и Edge выполните `playwright install chromium`.
С серверных IP Авито не пускает и браузер. Запросы идут с паузой 2–4 с и кэшируются на час
в `~/.cache/outfit_picker`.

Тесты: `.venv/bin/pytest`.
